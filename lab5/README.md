## Задание (вариант 12)

Вычислить CRC для пакета данных длиной N = 20 + 12 = 32 бита и для пакета из 250 бит. Порождающий полином `G = x⁷ + x⁶ + x⁴ + x³ + x² + x = 11011110`, длина CRC равна 7 бит. Добавить CRC к пакету, проверить пакет на приёмной стороне, затем по очереди исказить каждый бит пакета и подсчитать, сколько ошибок обнаружил приёмник.

## Что сделано

- Вычисление CRC как остатка от двоичного деления (к данным добавляются `n − 1 = 7` нулей, деление выполняется функцией `xoor` через XOR).
- Формирование пакета «данные + CRC» и проверка на приёмной стороне: нулевой остаток означает отсутствие ошибки.
- Расчёт для N = 32 и N = 250.
- Цикл из 257 итераций (250 + длина CRC): искажение одного бита, проверка функцией `hasError`, подсчёт обнаруженных и необнаруженных ошибок.

## Основные результаты

| Параметр | N = 32 | N = 250 |
|---|---|---|
| CRC | 0000110 | 0101100 |
| Длина пакета с CRC | 39 бит | 257 бит |
| Остаток на приёмнике без искажений | 0000000 | 0000000 |
| Итераций с искажением одного бита | — | 257 |
| Ошибка обнаружена | — | 257 |
| Ошибка не обнаружена | — | 0 |

Приёмник обнаружил все одиночные ошибки: полином `G` содержит несколько слагаемых и не является степенью `x`, поэтому искажение одного бита всегда даёт ненулевой остаток. Последний бит CRC равен нулю, так как в полиноме варианта 12 нет слагаемого `x⁰`.

## Запуск

1. Из папки с файлом выполнить `g++ 5lab.cpp -o 5lab`.
2. Запустить `./5lab`. В терминал выводятся данные, CRC, пакет, остаток на приёмнике, отчёт об ошибке и результат подсчёта обнаруженных и необнаруженных ошибок.
3. В коде задано `N = 250`. Для расчёта с N = 32 нужно изменить значение `N` в начале `main`.
