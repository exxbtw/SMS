# SMS — Лабораторная работа №4

**Дисциплина:** Основы систем мобильной связи (СибГУТИ, кафедра ТС и ВС)
**Тема:** Изучение корреляционных свойств последовательностей, используемых для синхронизации в сетях мобильной связи
**Студент:** Ю. С. Кузеванов, группа ИКС-431
**Преподаватель:** В. Г. Дроздова

## Задание

Сформировать две последовательности Голда длиной 31 бит на двух пятиразрядных регистрах сдвига по схеме рис. 4.5 (группа 431 нечётная): для номера в журнале 12 (x = `01100`, y = x + 7 = `10011`) и для x + 1, y − 5 (`01101`, `01110`). Исследовать автокорреляцию при циклических сдвигах и взаимную корреляцию на C++ и в Matlab (функции `autocorr` и `xcorr`), сравнить результаты.

## Что сделано

- C++: генерация последовательностей функцией `generate` (выход x5 ⊕ y5, обратные связи x1 = x4 ⊕ x5 и y1 = y2 ⊕ y5), вывод на экран.
- C++: поэлементный циклический сдвиг и таблица автокорреляции (сдвиг, сдвинутая последовательность, значение) по формуле `(совпадения − несовпадения) / N`.
- C++: взаимная корреляция двух последовательностей без сдвига.
- Matlab: те же последовательности; автокорреляция функцией `autocorr` (задержки 0–30); взаимная корреляция функцией `xcorr` с нормировкой `'coeff'` (биты переведены в ±1).
- Matlab: графики автокорреляции в зависимости от задержки (по `autocorr` и по `xcorr`), сравнение с результатами C++.

## Основные результаты

| Параметр | Значение |
|---|---|
| Последовательность 1 | `1111111110011111010011000001101` |
| Последовательность 2 | `1100000011100101000001001011110` |
| Взаимная корреляция, C++ | −0.0967742 |
| Взаимная корреляция, Matlab (`xcorr`) | −0.096774 |

| Сдвиг | C++ (циклический) | `autocorr` | `xcorr` |
|---|---|---|---|
| 0 | 1 | 1 | 1 |
| 1 | 0.354839 | 0.277713 | 0.322581 |
| 2 | 0.096774 | 0.028152 | 0.096774 |
| 3 | 0.225806 | 0.151320 | 0.193548 |

Автокорреляция имеет единственный пик, равный 1, при нулевом сдвиге; при остальных сдвигах в C++ значения лежат в пределах от −0.1613 до 0.3548. Взаимная корреляция двух последовательностей мала по модулю, то есть они слабо похожи.

Значения Matlab при ненулевых сдвигах отличаются от C++: в C++ сдвиг циклический, а `autocorr` и `xcorr` считают нециклическую корреляцию (`autocorr` дополнительно вычитает среднее).

## Запуск

**C++:**
1. Из корня папки лабораторной выполнить `g++ -o 4lab cpp/4lab.cpp`.
2. Запустить `./4lab`. В терминал выводятся две последовательности, таблица автокорреляции и значение взаимной корреляции.

**Matlab:**
1. Открыть Matlab, перейти в папку с файлом.
2. Запустить `sms4.m`. В консоль выводятся последовательности, автокорреляция (`autocorr`) и взаимная корреляция (`xcorr`), в отдельном окне строятся графики автокорреляции.
