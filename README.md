## Кратко о работах

**Занятие 1 (MATLAB).** Генерация сигнала `y(t) = 7·cos(2πft + π/13)`, оцифровка по теореме Котельникова, ДПФ, реализованное вручную, восстановление сигнала по отсчётам. Работа с записью голоса: прореживание, амплитудные спектры, влияние разрядности АЦП на спектр и ошибку квантования. Дополнительное задание: повышение высоты тона голоса (pitch shift).

**Занятие 2 (MATLAB).** Расчёт бюджетов восходящего и нисходящего каналов (максимально допустимые потери MAPL), построение потерь сигнала по моделям UMiNLOS, COST231-Hata и Walfish-Ikegami, определение радиуса соты и необходимого числа базовых станций для макро- и микросот.

**Занятие 4 (C++, MATLAB).** Формирование последовательностей Голда по схеме на регистрах сдвига, автокорреляция при циклических сдвигах, взаимная корреляция двух последовательностей. В MATLAB те же расчёты выполнены функциями `autocorr` и `xcorr` с построением графиков автокорреляции и сравнением результатов с C++.

**Занятие 5 (C++).** Вычисление CRC как остатка от двоичного деления пакета данных на порождающий полином (вариант 12, `G = 11011110`) для пакетов в 32 и 250 бит, проверка пакета на приёмной стороне, подсчёт обнаруженных ошибок при искажении каждого бита пакета.
