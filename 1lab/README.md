# SMS — Лабораторная работа №1

**Дисциплина:** Основы систем мобильной связи (СибГУТИ, кафедра ТС и ВС)
**Тема:** Временная и частотная формы сигналов. Преобразования Фурье. Дискретизация сигналов
**Студент:** Ю. С. Кузеванов, группа ИКС-431, вариант 12
**Преподаватель:** В. Г. Дроздова

## Задание (вариант 12)

Сигнал `y(t) = 7·cos(2πft + π/13)`, `f = 16 Гц`.

## Что сделано

- Генерация и визуализация непрерывного сигнала.
- Определение `f_max` и минимальной частоты дискретизации по теореме Котельникова (32 Гц), оцифровка, повтор для `fs` в 4 раза выше (128 Гц).
- ДПФ **вручную** (двойной цикл по формуле, без `fft`), оценка ширины спектра и объёма памяти.
- Восстановление сигнала по отсчётам и сравнение с оригиналом.
- Работа с записью голоса `sms.wav` (Fs = 48000 Гц): ручной расчёт `Fs`, прореживание `downsample` в 10 раз, амплитудные спектры оригинала и прореженного сигнала.
- Влияние разрядности АЦП (3/4/5/6 бит) на спектр и средняя ошибка квантования.

## Основные результаты

| Параметр | Значение |
|---|---|
| `f_max` | 16 Гц |
| `fs` мин. по Котельникову | 32 Гц |
| Память (double), 32 / 128 отсчёта | 256 / 1024 байт |
| Время ручного ДПФ, 20000 / 2000 отсчётов | 42.3 с / 0.42 с (рост ≈ N²) |
| Спектр после прореживания в 10 раз | обрезан до 2400 Гц |
| Ошибка квантования, 3 / 4 / 5 / 6 бит | 0.55473 / 0.2164 / 0.079288 / 0.043788 |

## Дополнительное задание: писклявый голос (pitch shift)

Файл `SMS1dop.m`. Высота тона повышается без изменения скорости и длительности (`Fs` не трогаем).

Алгоритм:

1. Голос режется на кадры по 50 мс с перекрытием 50 % и окном Ханна.
2. В каждом кадре: `fft` → растяжение оси частот в `m` раз (`k → round(m·k)`, `m = 2`) → симметрия `conj` для отрицательных частот → `ifft`.
3. Кадры возвращаются на свои места методом overlap-add.

Растяжение частот увеличивает расстояние между гармониками голоса, то есть поднимает основной тон.

1. Открыть Matlab, перейти в папку с файлами.
